# 落墨 InkMemo · 首次使用指引

> 这份指引写给第一次安装落墨的你：从装好到晶出第一条记忆、再到确认"AI 真的记得了"，跟着走一遍大约 10 分钟。
> 已经装好只想查某个面板怎么用？直接跳 [面板导览](#面板导览每个区是干嘛的)。

## 为什么会有落墨

聊到几百楼，AI 不是忘了"发生过那件事"，只是忘了**当时是什么样**——然后它不承认，硬着头皮往下圆：雪夜写成晴天，标志性的台词换成一句风格全不对的话。每一次"圆"，都在拆穿"我们共同经历过什么"这个信念。

落墨的答案是八个字：**细节是情绪的载体**。AI 不需要真的有情绪——它只要能读回当时的原台词、动作、光线、触感，写出来的下一句自然就带着情绪。所以落墨不做摘要（摘要丢掉的正是情绪载体），而是把你选中的剧情重写成保留 80~90% 原文质感的叙事，在聊到相关话题时自然递回给 AI。

我们想要的不只是 AI "知道发生过"，是它**记得当时的氛围**。

## 落墨的工作方式（30 秒版）

```
选一段聊天楼层 → 你自己的 LLM 把它重写成沉浸式叙事（不是摘要）
→ 自动生成触发关键词 → 你在预览里检查、确认写入
→ 之后聊天提到相关话题时，这段记忆自动注入上下文
```

落墨不用你手写世界书条目、不用自己想关键词；你要做的只有三件事：**选楼层、审预览、开触发**。

## 一、安装

1. ST 顶栏 → **扩展（Extensions）** → **Install extension**
2. 粘贴仓库地址：`https://github.com/shukeitei/SillyTavern-InkMemo`
3. 装完**强制刷新**页面（Ctrl+Shift+R / ⌘⇧R）

要求 SillyTavern **1.17.0+**。以后每次更新扩展也记得强刷——ES module 不强刷会跑旧代码。

装好后，扩展面板列表里会出现「**✦ 落墨 InkMemo**」一行——默认收起不占地方，点标题展开就是主面板。

## 二、首次配置：API 设置（必做，只做一次）

落墨用**你自己的** LLM 来重写记忆，所以第一步是告诉它调哪个模型。展开主面板最上方的「**API 设置**」区：

| 项目 | 填什么 | 说明 |
|---|---|---|
| API Endpoint | 如 `https://api.deepseek.com/v1/chat/completions` | 任何 OpenAI 兼容接口都行，要填**完整路径**（带 `/chat/completions`） |
| API Key | `sk-...` | 只存在你本地 ST 设置里，不会发给除该接口外的任何人 |
| Model | 如 `deepseek-chat` | 推荐 DeepSeek V3 级别以上，沉浸式结晶对模型能力有要求。填好 Endpoint + Key 后可点右侧「⟳ 拉取」从接口取回可用模型名，点输入框下拉选（省得去官网找改名后的原名） |
| Temperature | 0.6~0.8 | 默认 0.7 即可 |
| Max Tokens | **≥ 8192** | 结晶产出很长，填小了会被截断；一次晶很长的楼层用 16384 |

填完不用点保存，改动即时生效。

「**世界书设置**」区可以先不动——那里只是全局默认书名，每个聊天真正写进哪本书，会在第一次结晶时让你确认。

## 三、第一次结晶（跟着做）

打开一个**有一段完整剧情**的聊天，展开「**记忆结晶**」区。

先说一个理念：落墨是**主动结晶**，不是自动摘要——什么值得进入长期记忆，由你说了算。不是所有对话都需要被记住：日常寒暄让它过去就好，值得晶的是那些高光段落——某句决定性的台词、某个氛围拉满的瞬间、某次角色第一次破防。这也更接近人真实的记忆方式：不是每分每秒都记住，只记住有情绪浓度的瞬间。

**一次晶多大一段？以"一个事件"为单位，别攒。** 结晶的颗粒度直接决定日后触发准不准：一条结晶只装一个事件（一次约会、一场冲突、一段告白），关键词就聚焦，聊到相关话题时一击命中；反过来把一整个大剧情章节攒成一条，里面跨了好几个事件和时间点，关键词杂了，触发反而不准。具体几楼看你自己的聊天风格：喜欢长文的（一楼四五千字）大约 3~5 楼就是一个事件；短文来回的（一楼千字上下）大约 5~10 楼。数字不用死守，"剧情推进了一个进度"就是晶一次的时机。

1. **填楼层范围**：比如 `0 → 8`。楼层号就是 ST 每条消息左上角的 `#数字`。
   **不想手填？直接在楼层上点选**：每条消息的操作区（点 `⋯` 展开的那排按钮）里有一枚落墨墨滴 💧——在起点楼层点一下（图标亮起），再到终点楼层点一下，范围就自动填好并弹出结晶入口；**同一层点两下 = 只晶这一层**（适合单楼超长的大剧情）；点错了点一下提示气泡即可取消。桌面/手机通用。
   **被隐藏的楼层也照样能晶**——落墨按物理楼层号直接读聊天记录，你肉眼看到的 `#` 是几就填几：点了小幽灵隐藏的楼层、被"渲染消息数量"折叠起来没显示的楼层，全都读得到，不用取消隐藏也不用展开。（很多记忆/总结工具做不到这点——隐藏楼层不会发给 AI，AI 又不数楼层号，你说"总结 50~70"它看到的其实是另一段。落墨没有这个错位。）所以聊到几百楼才装落墨的也不用慌：保持隐藏，从 `#0` 开始分段一点点往上晶就行。
2. **点「预览提取内容」**：先看看这个范围抓到了哪些消息，确认没选错段落。
3. **点「✦ 开始结晶」**，选风格：
   - **沉浸式**（推荐）：重写成第三人称小说叙事，原台词、动作、心理、感官描写全保留，主线场景完整、支线要点化。落墨的初衷就是高保真——AI 触发到一条模糊记忆时会靠脑补编细节，沉浸式是防这个的；而且细节是情绪的载体，AI 读到"他单膝跪下脱拖鞋"和读到"他做了件温柔的事"，写出来的下一句温度完全不同。
   - **简洁式**：事件流概括，保真度低，情绪载体基本丢失，只适合"留个流水账就行"的场景。
4. **等待生成**（几十秒到几分钟，取决于楼层长度和模型速度），会弹出**结晶预览**。
5. **在预览里检查**：
   - 每条结晶是一张卡片，标题、正文、元数据、触发关键词**都可以点开手改**；
   - 重点看正文有没有编造原文没有的细节、关键词是不是这段剧情的"专属词"（改关键词的思路见下文 [触发关键词五档](#触发关键词五档想手调时看)）；
   - **不想要的条目可以整条删掉**：卡片右上角的 🗑（悬停卡片时显形）点一下变红「确删?」，再点一下即剔除，本次不写入——AI 有时会晶出些没什么意义的知识库条目，在这里直接扔掉即可，不影响其他条目。
6. **确认写入目标**：首次会让你确认写进哪本世界书（回忆录 / 角色知识库两本，不存在会自动创建）。**写入目标是按聊天绑定的**——这次确认后，这个聊天以后都写这两本，不会误写进别的角色的书。
7. **点「✦ 确认写入」**。完成后「条目管理」区就能看到新条目。

> **手机端**：预览会以内联卡片形式展开在面板里，操作一样。
> **桌面端连续结晶**：长剧情要分很多段晶，用「**⌖ 浮动结晶面板**」——一个悬浮小窗，自动记住上次晶到第几楼，点「最新」可把结束楼层填到当前最新层，不用来回翻扩展抽屉。

## 四、开启自动触发（让 AI"记得"）

展开「**触发引擎**」区：

1. 勾选「**启用自动触发注入**」——这是总开关，不勾什么都不会注入。
2. 其余选项先用默认值即可，含义如下：

| 选项 | 干嘛的 | 默认建议 |
|---|---|---|
| 匹配窗口 | 拿最近 N 条消息去匹配关键词 | 默认即可；调大更容易触发、也更容易误触发 |
| token 预算 | 单次注入的记忆总量上限，超出按分数高低取舍 | 默认即可 |
| 记忆截止层 | 开分支用的，见 [常见问题](#常见问题) | 平时留空 |
| 注入位置 | 记忆插进 prompt 的哪里 | 默认「聊天中（IN_CHAT）」即可 |
| 注入深度 | IN_CHAT 时插在倒数第几条消息处 | 默认即可 |

3. 点「**手动测试触发**」验一次：它会拿当前最近的消息跑一遍匹配，告诉你哪些条目会被注入。

### 怎么确认它真的在工作

- **触发日志**（面板最下面一个区）：每次注入了哪条、命中了什么词、得了几分、谁因为超预算被拦下——全在这里。**怀疑"注入了吗/为什么没注入"，第一站看这里。**
- **ST 的 token 计数**：发一条会命中关键词的消息，打开 ST 的 prompt/token 明细面板，「扩展程序（Extension）」一行 > 0 就说明记忆真的进了上下文。
- **最直观的**：直接问 AI 一个只有那段剧情里才有的细节，看它答不答得上。

## 面板导览：每个区是干嘛的

主面板从上到下七个区：

| 区 | 干嘛的 | 什么时候用 |
|---|---|---|
| **API 设置** | 配置结晶用的 LLM | 首次装好时；换模型/换 key 时 |
| **提取屏蔽** | 两件事：①**屏蔽标签**——提取楼层时整块剥掉的标签（一行一个，如 thinking、StatusBlock、details），成对 `<x>…</x>` 剥整块、未闭合起始标签连同其后到本楼层结尾一起剥，剥掉后既不进结晶也不吃 token。②**触发词主角名过滤**（默认开）——结晶产出的触发关键词里含主角名的词会被自动剔除（主角名每段记忆都有、区分度为零，收了会让条目互相挤兑）；单聊自动识别你和角色卡名，群聊要把男女主名填进「主角名单」，配角名不受影响。改完点「预览提取内容」/看结晶预览的关键词即可验证 | 楼层里混了状态栏/生图块/思维链等不想进记忆的块，或触发词老是被主角名污染时 |
| **世界书设置** | 两本书（回忆录/角色知识库）的全局默认书名 | 基本不用动；想换默认书名时 |
| **记忆结晶** | 选楼层 → 预览 → 结晶的主工作区 | 每次剧情告一段落想存档时 |
| **条目管理** | 已晶出的所有记忆的列表 | 想开关/编辑/删除某条记忆时 |
| **触发引擎** | 自动注入的总开关和参数 | 首次开启后基本不动；开分支时填截止层 |
| **触发日志** | 每次注入的完整记录 | 排查"注入了吗/为什么没注入" |

### 条目管理区细看

- 顶部是**统计**（多少条、多少启用），下面是条目列表。
- **时间线分桶**：如果你开过分支聊天，条目会按来源聊天分组显示（原线叫「A线·原线」，可以点铅笔给每条线起备注名）。整条时间线可以**一键整组开/关**——旧时间线不想再触发了，关掉整组就行。
- 每条条目上的操作：**开关**（单条启用/禁用）、**编辑触发条件**（改五档关键词）、**删除**。
- **「从世界书同步」与红点提示**：如果你在 ST 的世界书界面直接手改过落墨写入的条目，这里会亮红点提示两边不一致，点「从世界书同步」一键拉平。平时建议在落墨面板里改，不要两头改。

### 触发注入和世界书是什么关系？

落墨的自动触发走**自有存储**，不依赖世界书——写入世界书是同步备份（可导出、可在 ST 里翻看）。所以取消世界书绑定**不会**停掉落墨触发；想停用某条记忆，请用条目开关 / 时间线开关 / 关掉「启用自动触发注入」。

## 触发关键词五档（想手调时看）

结晶时关键词是自动生成的，多数时候不用管。但当某条记忆**该触发时不触发**（或反过来老误触发），就在条目管理里点「编辑触发条件」手调。五档的含义：

| 档 | 逻辑 | 分值 | 放什么词 |
|---|---|---|---|
| **must** | 全部命中才有资格触发，缺一即跳过 | 10（一次性） | 严格限定场景用；平时留空 |
| **core** | 命中任一给一次分（不累加） | 5（一次性） | 话题域泛词（如"美术馆""豆浆"）——单独不够过线，防误触发 |
| **any** | 每命中一个累加 | 3/个 | 事件专属名词：代号、称呼、专属物件、出场人名 |
| **boost** | 每命中一个累加 | 1/个 | 高光台词、专属梗——命中算强确认，不命中无损失 |
| **exclude** | 任一命中直接跳过 | — | "这条记忆在某些上下文不该出现"的反向排除 |

触发线是 **6 分**。所以最常见的组合：`core 词 + 1 个 any 词`（5+3=8 分）稳过；只出现一个 core 泛词（5 分）不会触发——这是刻意的防误触发设计。

调不触发的条目：优先给 any 档补几个"日后聊天真的可能被提起"的短词（单词优于长串——"弹力雨衣"比"弹力雨衣交易事件"命中率高得多）。老误触发的条目：检查是不是 any 里混进了服装/外貌这类 AI 叙事会自动填充的词，删掉或挪去 exclude。

还有一点刻意的设计要说明：**落墨不追求"绝对精准的召回"**。弱相关的记忆可以靠 any/boost 累加过线——这是在模拟人的联想：今天吃到粤菜，会想起以前跟某人吃粤菜的场景。这些被"顺便"勾起的弱相关记忆，正是 AI 回应里伏笔、暗线和人味的来源。所以手调关键词时不必把每条都修成只在唯一场景触发的精准检索器——留一点联想碰撞的空间，是特性不是 bug。

## 常见问题

**落墨是不是挺费 token 的？**
是的，而且这是公开的设计立场：**用 token 换保真度**。结晶产出保留 80~90% 原文体量，注入时给的也是完整叙事而非干巴摘要。如果你对每个 token 都很计较、宁可牺牲细节质感来省钱，落墨可能不适合你；如果你宁愿多花点 token 也要让 AI 别瞎编、让好剧情完整留下来——落墨就是为你做的。

**结晶质量不满意？**
沉浸式 prompt 对模型能力有要求，DeepSeek V3 级别以上效果较好。产出可以在预览弹窗里手改后再写入；Max Tokens 太小也会导致产出被截断变差。

**注入了但 AI 没反应？**
先看触发日志确认是否命中；再看 ST token 计数面板「扩展程序」一行是否 > 0。两个都正常而 AI 还是不接梗，多半是模型问题，试试把注入位置换成「剧情后锚点」。

**开了新分支，旧剧情把走向拽回去了？**
在**分支聊天**的触发引擎区填「记忆截止层」= 分支点楼层（从 #150 开的分支就填 150）：其他时间线里起始层 > 150 的结晶不再触发，本聊天自己晶的不受限。截止层按聊天分别记忆，留空即清除。也可以去条目管理把旧时间线整组关掉。

**换设备/重装 ST，记忆还在吗？**
条目数据存在 ST 的设置和世界书里，跟着你的 ST 用户数据走。世界书那份可以在 ST 里正常导出备份。

**隐私**
结晶时你选中的聊天记录会发送到**你自己填写的** API 端点，除此之外不与任何第三方通信。API Key 仅保存在你本地的 ST 设置中。

---

落墨做的事说到底很简单：**让 AI 在需要"记得"的时候，真的有东西可记**——让那些你投入了情感的高光瞬间，不至于在几十楼之后被一句干巴巴的概述辜负。
