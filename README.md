# 落墨 InkMemo

SillyTavern 长程记忆扩展：把聊过的剧情**结晶**成回忆录与角色知识库，聊到相关话题时**自动触发注入**——让你的角色真正记得你们的故事。

> An immersive long-term memory extension for SillyTavern: crystallize past chats into memoir & knowledge entries, auto-inject them when the conversation touches related topics. Chinese-first, works with any OpenAI-compatible API.

## 它解决什么问题

- 聊了几百楼，AI 早忘了你们第一次见面的细节
- 手写世界书条目太累，还要自己想触发关键词
- 摘要式记忆把剧情压成干巴巴的流水账，回忆起来没有味道

落墨的思路：选一段楼层 → 交给你自己的 LLM（DeepSeek 等）重写成**沉浸式小说叙事**（忠实于事件、自由于文字，不是摘要）→ 自动生成三层触发关键词 → 写入世界书 + 落墨自有存储 → 后续聊天命中关键词时自动注入上下文。

## 功能一览

- **双模式结晶**：沉浸式（场景分级 A/B/C，主线全保留、支线要点化）/ 简洁式（事件流概括）。**建议默认沉浸式**——落墨的初衷是高保真还原回忆、防止 AI 触发到一条模糊记忆时靠脑补编细节；简洁式保真度低，只适合"留个流水账就行"的场景
- **结晶预览编辑**：写入前可改标题、正文、元数据、关键词；写入目标按聊天绑定，防误写进别人的世界书
- **智能触发引擎**：must/core/any/boost/exclude 五档关键词 + 权重评分 + 阈值，每条可视化编辑
- **时间线分桶**：开分支后按来源聊天分桶管理，旧时间线可整组关闭；「记忆截止层」防分支被未来剧情剧透
- **浮动结晶面板**：连续分段结晶不用来回翻抽屉，自动记住上次晶到第几楼
- **建议同步**：在 ST 世界书界面手改过条目？面板会亮红点提示一键拉平
- **注入日志**：每次注入了什么、为什么命中、谁被拦下，全部可查

## 安装

ST 顶栏 → **扩展（Extensions）** → **Install extension** → 粘贴本仓库地址：

```
https://github.com/shukeitei/SillyTavern-InkMemo
```

或手动：把本仓库放进 `SillyTavern/public/scripts/extensions/third_party/` 下任意文件夹。

> 需要 SillyTavern 1.17.0+。更新扩展后请**强制刷新**页面（Ctrl+Shift+R / ⌘⇧R），ES module 不强刷会跑旧代码。

## 快速上手

> 📖 更详细的逐步教程（每个面板干嘛的、第一次结晶怎么走、关键词怎么手调）见 **[首次使用指引](docs/使用指引.md)**。下面是速通版：

1. 扩展面板找到「✦ 落墨 InkMemo」→ **API 设置**：填一个 OpenAI 兼容接口（推荐 DeepSeek：endpoint `https://api.deepseek.com/v1/chat/completions`，model `deepseek-chat`），Max Tokens 建议 ≥ 8192
2. **记忆结晶**区填楼层范围（如 `0 → 30`）→ 预览提取内容 → 选「沉浸式结晶」（推荐）或「简洁式结晶」（概括风格，保真度低）
3. 在预览弹窗里检查/修改产出，**确认写入目标世界书**（首次会要求你手动确认书名，之后记住绑定）→ 确认写入
4. **触发引擎**区勾选「启用自动触发注入」——之后聊天中提到相关话题，对应记忆会自动注入
5. 连续结晶长剧情：用「⌖ 浮动结晶面板」，它记得你晶到第几楼

## 常见问题

**触发注入和世界书是什么关系？**
落墨的自动触发走自有存储 + `setExtensionPrompt` 注入，**不依赖**世界书绑定；写入世界书是同步备份（可导出、可在 ST 里查看）。取消世界书绑定不会停掉落墨触发——要停请用条目/时间线开关或关闭「启用自动触发注入」。

**结晶质量不满意？**
沉浸式 prompt 对模型能力有要求，DeepSeek V3 级别以上效果较好。产出可以在预览弹窗里手改后再写入。

**注入了但 AI 没反应？**
看「触发日志」确认是否命中；再到 ST 的 token 计数面板看「扩展程序」一行是否 > 0。

**开了新分支，旧剧情把走向拽回去了？**
在分支聊天的触发引擎区填「记忆截止层」= 分支点楼层；或在条目管理里把旧时间线整组关掉。

## 隐私说明

结晶时你选中的聊天记录会发送到**你自己填写的** API 端点，除此之外不与任何第三方通信。API Key 仅保存在你本地的 ST 设置中。
